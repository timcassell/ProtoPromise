# Change Log

## v3.5.2 - September 25, 2026

Fixes:

- Fixed pending `Promise.Merge`, `Promise<T>.All`, and `PromiseMergeGroup` with the same result type corrupting each other's results.
- Fixed `IndexOutOfRangeException` from `PromiseYielder` when many yield instructions of the same type are pending, which stopped `PromiseYielder` from processing further instructions.
